## About the Project

Roomify is a collaborative project developed by a team of three members. The application aims to provide users with an interactive web-based platform for exploring room furnishing and interior design concepts using AI technology.

The project focuses on creating an accessible and user-friendly web experience.

## My Role & Contributions

I was responsible for the web development and deployment aspects of this project.

My contributions included:

- **Web Development:** Building and developing the application's web interface.
- **UI Implementation:** Creating the user-facing layout and interface.
- **Application Integration:** Connecting the web interface with the application's functionality.
- **Deployment:** Deploying the application using Hugging Face Spaces.
- **Publishing:** Making the application accessible online.
